# シノビガミ資料庫（ローカル保存版）

Claude API と Claude ストレージを使わず、このPC上の Node.js サーバーへ保存する版です。

## 起動

1. `start-server.bat` をダブルクリックします。
2. ブラウザーで `http://127.0.0.1:8787` を開きます。

データは `data/store.json`、アップロード画像は `uploads` に保存されます。サーバーを終了してもデータは残ります。

## 忍法CSVの取り込み

サーバーを起動したまま、別のPowerShellで次のように実行します。既に登録済みの同じ忍法は重複登録しません。

```powershell
node .\import-ninpo-csv.js "C:\path\to\忍法データベース.csv"
```

## TRPGSheetバックアップの取り込み

キャラシ画面の `TRPGSheet .bab を取り込む` から、TRPGSheetで出力したシノビガミ用 `.bab` ファイルを選択します。キャラクター名、プレイヤー名、表の顔、信念、階級、忍法、背景、人物欄、忍具を取り込みます。資料庫に未登録の忍法などは、取り込んだキャラシのメモに記録されます。

## バックアップ

サーバーを止めたうえで、`data/store.json` と `uploads` フォルダーをコピーしてください。

## 注意

この構成は既存のClaudeストレージの内容を自動では移せません。既存データはエクスポートできる場合に限り、別途インポート処理を追加できます。

既定ではこのPCだけからアクセス可能です。LAN上の別端末へ公開する場合は、`HOST=0.0.0.0` を指定して起動し、Windowsファイアウォールを設定してください。認証機能はまだないため、信頼できるネットワーク以外へ公開しないでください。
